# Telco Customer Churn Analysis

A Data Science project focused on analyzing telecom customer churn, identifying the factors that influence customer retention, and developing machine learning models to predict potential churn.

## Project Objectives
- Analyze customer demographics, account details, and service usage.
- Identify key factors associated with customer churn.
- Perform exploratory data analysis and statistical hypothesis testing.
- Build and compare machine learning models.
- Develop data-driven recommendations to improve customer retention.

## Technology Stack
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Planned Machine Learning Models
- Logistic Regression
- Random Forest
- Gradient Boosting

## Dataset
IBM Telco Customer Churn dataset. The dataset will be obtained from a public source, subject to its licensing and usage terms.

## Project Status
**Current stage:** Project planning completed. Data exploration, preprocessing, model development, and evaluation are planned next.
